# Alben Roy — Premium Photographer Portfolio

An editorial, cinematic photography portfolio website for **Alben Roy** ([@albenroy](https://instagram.com/albenroy)), combining Apple-inspired minimalism, magazine typography, and interactive camera viewfinder mechanics.

---

## ✨ Features

- **01 — Cinematic Camera Viewfinder Intro**: Animated focus brackets, rotating focus ring, exposure compensation readout, aperture guides, and shutter curtain snap.
- **02 — Editorial Hero Experience**: Full-screen portrait showcase, camera telemetry capsule (`FE 85mm F1.4 GM · f/1.4 · 1/640s · ISO 100`), interactive frame carousel, and camera focus distance scale (`0.5m · 0.8m · 1.4m [LOCK] · ∞`).
- **03 — Selected Photography Archive**: Asymmetric editorial layout with 9 authentic photographs across *Portraits*, *Outdoor Portraits*, *Editorial*, and *Creative Sessions*.
- **04 — Camera Microinteractions**: Custom camera focus reticle cursor, focus brackets locking on hover, aperture blade transitions, film-frame numbering (`FRM 01` – `FRM 09`), and synthesized Web Audio mechanical camera shutter click.
- **05 — Featured Photo Stories**: Deep-dive photo essays with cover frames, supporting triptych sequences, location tags, and behind-the-scenes narrative notes.
- **06 — Authentic About Section**: Featuring verified portrait of Alben Roy, creative philosophy, core principles (*Natural Light Sculpting*, *Candid Emotional Resonance*, *Contextual Storytelling*), and community stats.
- **07 — Book a Photoshoot**: Clean commission inquiry form with interactive photoshoot type selectors, date picker, and animated camera shutter CTA.
- **08 — Cinematic Fullscreen Lightbox**: High-resolution zoom, dual-curtain shutter blade animation, and full camera EXIF/exposure specifications.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Motion**: [Framer Motion](https://www.framer.com/motion/) & CSS keyframe animation
- **Icons**: [Lucide React](https://lucide.dev/)
- **Sound**: Web Audio API camera shutter synthesizer (zero external audio file dependencies)

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/abhinand-me/alben-roy-portfolio.git
cd alben-roy-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.
